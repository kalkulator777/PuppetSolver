# Puppet Cube V2 — решатель

Сайт, который собирает **MoYu Puppet Cube V2** по шагам: вы вводите цвета кубика, а он показывает
решение ход за ходом с 3D-анимацией. Работает без интернета и без установки: обычный HTML + JavaScript,
подходит и для телефона.

## Как запустить

**Проще всего (компьютер или телефон):** откройте файл `puppet-solver.html` в браузере.
Это всё приложение в одном файле — его можно просто скинуть на телефон (мессенджером, по кабелю)
и открыть в Chrome/Safari/Firefox.

**Из папки проекта:** откройте `index.html` двойным щелчком.

**На телефоне через компьютер по Wi‑Fi:** в папке проекта выполните

```
python3 -m http.server 8000
```

и на телефоне (в той же сети) откройте `http://<IP-адрес-компьютера>:8000`.

## Как пользоваться

1. **Форма куба.** Решатель работает с кубиком, который уже имеет форму куба (ничего не выпирает).
   Если кубик «разъехался», загляните во вкладку «Форма куба»: там типичные фигуры и формулы,
   которые возвращают форму.
2. **Как держать.** Крошечный уголок — сверху‑спереди‑справа (на гранях U, F, R видны «крестики» из маленьких
   квадратиков), главный блок (цельный 2×2×2 с тремя гладкими гранями) — снизу‑сзади‑слева.
   Все ходы записаны для этого положения, перехватывать кубик не нужно.
3. **Ввод.** Отметьте цвета на развёртке. Затем приложение трижды попросит повернуть средний слой на 180°
   (`M2`, `E2`, `S2`) — так становятся видны спрятанные детали — и ввести подсвеченные цвета.
   После каждого такого поворота слой нужно вернуть назад.
4. **Решение.** Кнопка «Ход ▶» показывает анимацию следующего хода и его описание, «▶ Авто» проигрывает подряд.

Есть ещё **симулятор** (покрутить модель, перемешать, решить) и **справка** по обозначениям.

### Обозначения

| Ход | Что поворачивать |
|---|---|
| `R`, `U`, `F` | тонкий внешний слой (ряд маленьких квадратиков) справа / сверху / спереди |
| `L`, `D`, `B` | толстая половина слева / снизу / сзади |
| `M`, `E`, `S` | средний тонкий слой (M — как L, E — как D, S — как F) |
| `Rw`, `Uw`, `Fw` | половина справа / сверху / спереди (тонкий слой + средний) — как ход кубика 2×2 |

`'` — против часовой стрелки, `2` — на 180°.

## Как это устроено

Puppet Cube V2 — это обычный кубик 3×3, сдвинутый к одному углу: детали на сторонах L, D, B продолжены наружу
и снаружи выглядят как кубик 2×2 (главный блок, три больших блока, три L‑образных блока), а на гранях R, U, F
видны маленькие детали внутреннего 3×3 («крестики»).

* `js/puppet-core.js` — модель: каждая деталь — набор кубиков‑вокселей, повороты вокруг ядра,
  проверка, не упираются ли выступающие части при повороте.
* `js/solver.js` — решатель: 1) блоки — оптимальные последовательности поворотов половинок (полный перебор
  474 264 состояний, не больше 13 ходов); 2) центры — средними слоями; 3) рёбра — 3‑циклы из туториалов
  (`M2 U' M U2 M' U' M2` и др.) с подготовительными ходами (библиотека из 1754 проверенных макросов).
  Каждый ход итогового решения повторно проверяется моделью.
* `js/render.js` — 3D‑отрисовка на Canvas без внешних библиотек.
* `js/app.js`, `index.html`, `css/style.css` — интерфейс.
* `js/data.js` — сгенерированные данные (таблица блоков, библиотека рёбер, маски столкновений).

Модель проверена на опубликованных данных: кратчайший обмен двух больших блоков в ней — ровно 10 ходов,
обмен L‑блоков — 11, и найденные формулы совпадают с полученными компьютерным перебором в статье
«Puppet Cubes» (viXra 2201.0038); алгоритмы из гайдов SommerCubes и Cuber Stu выполняются в тех положениях,
которые указаны авторами.

### Для разработки

```
python3 tools/gen_data.py      # пересчитать js/data.js (≈1 мин)
python3 tools/gen_vectors.py   # эталонные прогоны Python-модели для тестов
node tests/run-tests.js        # тесты модели и решателя
python3 tools/build_single.py  # собрать puppet-solver.html
```

## Источники

* «Puppet Cubes», viXra 2201.0038 — описание V1/V2, оптимальные обмены блоков, алгоритмы рёбер V2.
* Rune Vang Sommer (SommerCubes) — гайды по Puppet Cube V1/V2 и типичные фигуры для возврата формы.
* Cuber Stu, J Perm — видеоразборы Puppet Cube 1 и 2.
